# Fix: localize web application interface

## Task

Localize web application interface text for English, Italian, Spanish, German,
and French. Keep user-created poll and group content in its original language.
Use English as the fallback language, persist the selected language on the
device, and format dates and fixed USD plan prices for the selected locale.

## Problem

Several interface strings on the landing page, poll cards, plan selection,
subscription details, terms header, and poll-result chart tooltips were written
only in English. Plan limits and prices were stored as English display strings,
which prevented locale-aware number and currency formatting. Poll voting also
did not submit the selected option IDs to the API or show its result to the
user.

## Solution

- Added a shared `ui` translation namespace with Italian, Spanish, German, and
  French translations for plan, poll, legal, loading, access, and results UI.
  English remains the fallback language and language selection remains
  device-local.
- Added shared locale-aware date and USD currency formatters. Poll close dates,
  profile dates, plan prices, member limits, and live-user limits now use the
  active locale while preserving fixed USD prices.
- Replaced English interface strings in the landing plans section, plan cards,
  subscription summary, poll cards, demographic-chart tooltip, and terms-page
  navigation and header with translations. User-provided poll titles,
  descriptions, and options are not translated.
- Changed plan metadata from preformatted display text to raw price and limit
  values so the UI can localize those values at render time.
- Connected poll vote submission to `POST /polls/:id/votes` with the saved
  bearer token, disabled repeat submissions, displayed success or API errors,
  and refreshed the poll cache after a successful vote.
- Added a web application test that verifies vote submission sends the selected
  option ID and authorization header.
- Updated the README description of the repository's AI-driven development
  workflow.

## Validation

- Added unit coverage for authenticated poll vote submission.
- Test suite was not run while preparing this PR description.
